# Technical Analysis Report: Storm-3358 ARTEX Agentic AI Abuse Targeting Financial Sector (2026-11-08)

## Executive Summary

Storm-3358, a financially motivated threat group assessed as Cambodia-based, has been observed using ARTEX — an open-source, multi-agent LLM penetration testing framework — to target financial institutions in Southeast Asia and select global organizations since October 2026. Microsoft Threat Intelligence published a report on November 6, 2026 detailing the group's operations. The actors exploit internet-facing systems via anonymous file uploads and server-side request forgery (SSRF), then deploy ARTEX agents that autonomously download and install remote access trojans including WISP, AdaptixC2, and vshell using curl and netcat. ARTEX is a Go-based framework with a Next.js frontend that orchestrates reconnaissance through exfiltration using any LLM backend. Approximately 1,400–1,800 exposed ARTEX instances have been observed in the wild. Separately, Storm-0940 (China-linked) has used ARTEX in a ConnectWise supply-chain compromise affecting 2,250+ Microsoft 365 tenants.

## Background: ARTEX Framework

ARTEX is an open-source multi-agent penetration testing framework written in Go with a Next.js web frontend, published on GitHub in approximately July 2026. It uses LLM-driven agents to autonomously perform reconnaissance, vulnerability scanning, exploitation, credential harvesting, and exfiltration. ARTEX accumulates discovered assets and vulnerabilities into a graph and supports English, Korean, Mandarin, Spanish, and Japanese interfaces. Its default tooling includes Nmap, curl, wget, Python HTTP clients, and headless Chromium via Playwright. The framework can use any LLM model backend, making it model-agnostic.

ARTEX exposes a distinctive REST API: `GET /api/health` returns `{"ok":true,"service":"artex","version":"..."}` and `GET /api/auth/status` returns `{"initialized":true|false}`. Censys observed approximately 1,400 exposed instances across 800 deployments as of November 4, 2026; Check Point counted over 1,800 as of November 5.

## Root Cause: Exposed Internet-Facing Services + Autonomous AI Exploitation

Storm-3358 exploits internet-facing services through anonymous file upload vulnerabilities and SSRF flaws. Once initial access is achieved, ARTEX agents autonomously:
1. Perform reconnaissance and vulnerability scanning
2. Download RATs (WISP, AdaptixC2, vshell) using curl and netcat
3. Establish persistence via web shells and cron jobs
4. Harvest credentials from compromised systems and public sources
5. Enumerate and abuse cloud APIs for lateral movement
6. Dump databases and exfiltrate data

The group also conducts brute-force and password-spray attacks against cloud identities.

## Remediation

1. **Block known C2 IPs** at the network perimeter: 199.19.95.66–68, 91.92.240.238, 85.11.168.45, 85.11.167.52, 178.16.54.129, 31.77.229.35
2. **Scan for exposed ARTEX instances** on internal networks using the `/api/health` endpoint signature
3. **Audit internet-facing services** for anonymous file upload vulnerabilities and SSRF flaws
4. **Review curl/netcat usage** on servers for unauthorized RAT downloads
5. **Rotate credentials** if any systems communicated with the listed C2 infrastructure
6. **Enable MFA** on all cloud identities; monitor for password-spray activity
7. **Deploy detection rules** from this report to IDS/SIEM platforms
