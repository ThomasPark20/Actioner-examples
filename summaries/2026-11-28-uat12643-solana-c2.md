## Executive Summary

UAT-12643 is a suspected North Korea-aligned, financially motivated threat actor tracked by Cisco Talos (low-confidence attribution). The campaign deploys three malware families: **Overlord RAT** (a Go-based modular RAT with 35 commands), the **Good Game** infostealer (Python/PyInstaller-packed), and a **cryptocurrency clipboard hijacker** (C++ x64). The distinguishing feature is the use of **Solana blockchain transaction memos** to store AES-256 encrypted C2 WebSocket URLs, enabling bulletproof infrastructure rotation without updating deployed implants. Initial access is achieved through malicious LNK files, HTA stagers, and MSBuild inline tasks that abuse LOLBIN utilities (MpCmdRun.exe, certutil, mshta.exe, msbuild.exe).

## Solana Blockchain C2 -- Technical Detail

The Overlord RAT resolves its active C2 WebSocket URL from Solana blockchain transaction memos:

1. The implant queries a public Solana JSON-RPC endpoint using `getSignaturesForAddress` to retrieve the newest confirmed transaction for the operator's wallet
2. It then calls `getTransaction` with `jsonParsed` encoding to extract the transaction's instruction data
3. The SPL Memo Program instruction data is filtered: only entries exactly 43 characters long are processed
4. The 43-character memo is AES-256 decrypted to yield a Base58-encoded WebSocket URL
5. The implant connects to the resolved C2 and begins beaconing

**Infrastructure resilience:** When a C2 server is sinkholed, the operator broadcasts a new Solana transaction with an updated encrypted memo. The implant picks up the new address on its next poll without requiring a binary update. This makes traditional domain/IP blocklists ineffective as the sole defense.

**Detection challenge:** Solana RPC queries use standard HTTPS POST to public node providers (Helius, QuickNode, Tatum, etc.). Without TLS inspection, only DNS-level monitoring of queries to Solana RPC providers is feasible. The memo size limit is 566 bytes; the filtered 43-character length is distinctive.

## Hunting Queries

```spl
index=proxy OR index=network
| where match(_raw, "(?i)getSignaturesForAddress") OR match(_raw, "(?i)getTransaction.*jsonParsed")
```

## Notes for Review

- **Solana wallet addresses not disclosed:** Talos did not publish the Solana wallet addresses used for C2 resolution. Network detection must focus on RPC method patterns rather than wallet-specific indicators.
- **HTTPS limitation:** Snort/Suricata rules for Solana RPC traffic are effective only on cleartext HTTP or with TLS inspection enabled. DNS-based monitoring of Solana RPC providers (Helius, QuickNode, Tatum) remains effective regardless.
- **Attribution confidence:** Talos rates North Korea alignment as low confidence. The attribution rests on similarities to previously documented operations rather than confirmed links.
- **Overlord is open-source:** The RAT is a publicly available Go-based tool, making hash-based detection brittle. Behavioral and string-based detections are more durable.
- **Good Game stealer hides console:** Uses GetConsoleWindow/ShowWindow with a tkinter GUI decoy and daemon threads to avoid user suspicion.
- **Port-based detections (5656, 5959, 5173):** These are advisory-specific and may change between campaigns. Deploy alongside behavioral rules.
- **ipwhois.app DNS rule (SURI-7):** Low confidence due to legitimate use by many applications. Best used as a hunting indicator, not an alerting rule.
