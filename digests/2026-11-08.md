## Qualifying Threats

### 1. CVE-2026-116606 + CVE-2026-111560: Barracuda ESG Pre-Auth Root RCE Chain
- **Severity:** Critical (CVSS 9.3 + 8.6)
- **Status:** Weaponized PoC exists; no confirmed in-the-wild exploitation
- **Summary:** Two chained vulnerabilities in Barracuda Email Security Gateway allow unauthenticated remote code execution as root. A password-change flaw (CVE-2026-116606) grants unauthorized session access, enabling exploitation of a command injection in timezone handling (CVE-2026-111560) via crafted backup restore. watchTowr published full analysis and PoC tool on Nov 5. Patched in ESG 9.4.0.029+.
- **Rules:** 2 Sigma (high, low) + 1 Snort (high) + 1 Suricata (high) — all compiled
- **Report:** `summaries/2026-11-08-barracuda-esg-cve-2026-116606.md`

### 2. CVE-2026-123158: OpenSSH "SSHole" Authentication Bypass
- **Severity:** High (CVSS 8.1)
- **Status:** Active exploitation within 9 hours of disclosure
- **Summary:** Authentication bypass in OpenSSH on musl libc systems (Alpine Linux, OpenWrt, Buildroot). Passwords 257–1024 bytes cause crypt() to return `*`, matching passwordless accounts including root. Affects ~22M internet-facing SSH systems. Fixed in OpenSSH 10.6p2.
- **Rules:** 2 Sigma (high, medium) + 1 Snort (medium) + 1 Suricata (medium) + 1 Sigma IP IOC (medium) — all compiled
- **Report:** `summaries/2026-11-08-openssh-sshole-cve-2026-123158.md`

### 3. cPGuard Update Channel Supply Chain Attack
- **Severity:** Critical (supply chain compromise)
- **Status:** Active exploitation; ~2,950 servers compromised in 70-minute window
- **Summary:** Attacker compromised OPSSHIELD's update infrastructure and pushed malicious cPGuard update installing a hidden setuid-root shell, persistence cron job, and credential exfiltration across ~2,950 customer Linux servers. Billing records for ~7,900 customer accounts also stolen. Remediated in v5.88.26.
- **Rules:** 2 Sigma (high) + 1 Snort (high) + 1 Suricata (high) + 1 YARA (high) — all compiled
- **Report:** `summaries/2026-11-08-cpguard-supply-chain.md`

### 4. CVE-2026-98432: Linux Kernel IPv4 TCP Use-After-Free RCE
- **Severity:** Critical (CVSS 9.8)
- **Status:** PoC race trigger exists; AI-generated working remote root exploit demonstrated
- **Summary:** Use-after-free in Linux kernel IPv4 TCP IP options handling (since Linux 4.4) allows unauthenticated remote code execution. Race condition triggered by retransmitted SYN packets with Record Route or Timestamp options. Major distributions have shipped patches.
- **Rules:** 2 Sigma (high, medium) + 2 Snort (high) + 2 Suricata (high) — all compiled
- **Report:** `summaries/2026-11-08-linux-tcp-cve-2026-98432.md`

### 5. CVE-2026-19868: SonicWall SonicOS SSLVPN SAML Authentication Bypass
- **Severity:** High (CVSS 7.1–7.5)
- **Status:** CISA KEV listed; active exploitation under investigation
- **Summary:** Authentication enforcement flaw in SonicWall SonicOS SSL VPN allows SAML bypass (including MFA) with valid alternate credentials. Affects Gen7/Gen8 firewalls. No workarounds; upgrade required. Federal remediation deadline Nov 20, 2026.
- **Rules:** None — no viable network-level detection (logical auth bypass with no public technical details)
- **Report:** `summaries/2026-11-08-sonicwall-sslvpn-cve-2026-19868.md`

### 6. ARTEX Framework / Storm-3358 Financial Sector Campaign
- **Severity:** High-Critical (multiple RATs, supply chain, LLMjacking)
- **Status:** Active campaign targeting Southeast Asian financial institutions
- **Summary:** Cambodia-based Storm-3358 uses ARTEX agentic AI framework for automated credential abuse, Azure workload hijacking, and LLMjacking via xcai.pro. Confirmed breaches at South Korean banks. 17 C2/infrastructure IPs identified across Microsoft and Hunt.io investigations. Separately, 6 backdoored Docker images impersonate ARTEX AI tooling with unauthenticated root shell via verifyCaptcha() backdoor.
- **Rules:** 5 Sigma (high) + 2 YARA (high) + 1 Snort bundle/8 rules (high) + 1 Suricata bundle/3 rules (high) — all compiled
- **Report:** `summaries/2026-11-08-artex-storm3358-financial.md`
